# Food Delivery Data Analysis Project

## 📌 Project Overview
This project combines multiple datasets from different formats (CSV, JSON, SQL) to create a final dataset for analysis.

## 📂 Files Used
- orders.csv → Transaction data
- users.json → User data
- restaurants.sql → Restaurant data

## 🔄 Data Processing
- Loaded all datasets
- Performed left joins
- Created final dataset

## 📁 Output File
final_food_delivery_dataset.csv

## 📊 Analysis Goals
- Order trends
- User behavior
- City & cuisine performance
- Membership impact
- Revenue analysis

## 🛠 Tools Used
- Python
- Pandas
- Jupyter Notebook
- GitHub
